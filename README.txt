PDF MERGER - UP TO 200 FILES

1. Install Python 3.10 or newer.
2. Open Command Prompt in this folder.
3. Install dependencies:
   python -m pip install -r requirements.txt
4. Start the app:
   python app.py
5. Open this address in your browser:
   http://127.0.0.1:5000

Select 2 to 200 PDF files and click MERGE PDF FILES.
The merged file downloads as Merged_PDF.pdf.

The app listens only on your own computer (127.0.0.1).
Maximum individual PDF size: 200 MB. Actual batch size depends on available RAM.
Stop the app with CTRL+C in Command Prompt.
